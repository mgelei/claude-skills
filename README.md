# claude-skills
Collection of useful and semi-useful skills for Claude, usually optimized for consumption via the web/phone UI of Claude.ai

| Skill | Description |
| --- | --- |
| [`bootstrap-project`](bootstrap-project/) | Convert a rough software or product idea into durable, reviewable project foundations (an AGENTS.md and a docs/project-spec.md) through inspection, a decision-register-driven interview, and targeted research. |
| [`challenge-me`](challenge-me/) | Adversarial stress-testing interviewer that interrogates a proposed plan, architecture, or design one decision at a time and produces a self-contained decision record. |
| [`prompt-architect`](prompt-architect/) | Turns rough prompt ideas into complete, production-ready prompts for Claude. It uses an iterative clarification workflow and a stable numbered decision ledger. |
